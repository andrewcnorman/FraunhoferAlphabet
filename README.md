Fraunhofer Alphabet
===================

This repository contains files relating to the "Fraunhofer Alphabet" activity.

The worksheet was written by Andrew C. Norman (Science Department, Our Lady's Catholic College).  Most code is from Charles S. Adams and Ifan G. Hughes with minor changes.

Compiling LaTeX code
--------------------

The files will only compile properly when the following
LaTeX packages are installed:
- siunitx
- tikz
- graphicx

The document can be compiled by issuing the commands
- `pdflatex filename.tex`

Documents may need to be compiled a number of times to
update all of the internal references, and to generate the
table of contents data.
